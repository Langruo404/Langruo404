## Featured Projects

### Bridge Defect Detection & Quantification System

结合道路桥梁与桥隧工程背景，参与并学习桥梁病害视觉检测与量化项目。项目基于 YOLO 目标检测框架识别桥梁裂缝、病害区域等目标，并进一步结合深度学习算法对病害特征进行量化分析。

项目关注点包括：

* 桥梁裂缝、病害区域等检测对象的工程语义理解
* YOLO 目标检测、数据标注、模型训练与结果评估流程
* 检测结果到病害量化指标的后处理与系统输出
* 工程检测报告、维护建议与算法输出之间的衔接
* “工程需求 → 视觉算法 → 病害量化 → 系统表达”的需求分析过程

Keywords: YOLO, Computer Vision, Bridge Inspection, Defect Detection, Quantification, Engineering AI, Requirement Analysis.

### Local LLM Telegram Bot Memory System

围绕本地 LLM Telegram Bot，设计并实现对话上下文、运行摘要、结构化记忆与检索结果的装配方案，用于探索小模型在长对话场景下的连续性与上下文预算问题。

项目关注点包括：

* 最近消息、运行摘要、分段摘要与结构化记忆的边界划分
* 基于 SQLite 的消息、上下文与摘要存储
* 面向本地 LLM 的 prompt assembly 策略
* 小模型工具调用步数、记忆污染与上下文预算控制
* 结合个人 AI 工作台与专业知识库实践，探索 FTS、Embedding 与 RAG-style 检索在长期记忆和领域知识库中的应用

Keywords: TypeScript, Node.js, Telegram Bot, SQLite, Local LLM, Structured Memory, FTS, Embedding, RAG, Prompt Assembly.
